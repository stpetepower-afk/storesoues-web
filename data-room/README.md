## Two honesty corrections applied to the source document

A data room is only as valuable as it is trustworthy, so two things from the
draft were adjusted here:

1. **Naming:** the draft referenced `hallelujah-heos.netlify.app`. The canonical
   public site is **`hallelujah-one.netlify.app`** (per the naming
   standardization). This data room uses the canonical name only.
2. **Compliance language:** the draft said "compliant with the GENIUS Act
   framework, HUD CoC standards, and W3C protocols." Nothing here has been
   certified compliant by any authority. This data room says **"designed to
   align with"** those frameworks — which is true and defensible. Never present
   uncertified alignment as certified compliance to a funder or regulator.
