Wire it to live data

  1. Create a free Apify account at apify.com — it includes ~$5/mo of free credit.
  2. Run the Instagram Post Scraper actor on a public profile; a run costs cents. Export the dataset as JSON.
  3. Paste that JSON into the panel above, add your follower count, and hit Render dashboard.
  4. For auto-updating data: in claude.ai go to Settings → Connectors → Add custom connector and paste Apify's MCP server URL, then ask Claude to refresh this dashboard from it.
Tip: add a custom connector rather than a one-off prebuilt run — the connector re-fetches fresh data each time you ask, so the dashboard stays current instead of freezing on the day you built it.
