# Pilot Replication Framework — St. Petersburg → Florida → National → Global

> Roadmap document. Phase 0 is the real, current pilot; later phases are
> planned targets, not achieved milestones.

## Phase 0: St. Petersburg (Current)
- **Participants:** 10–15 (target)
- **Key Partners:** Mac House, PSTA, CareerSource Pinellas
- **Measurement:** Monthly EMI (Economic Mobility Index) baselines

## Phase 1: Tampa Bay Region (Month 6–12)
- **Locations:** Pinellas, Hillsborough, Pasco
- **Target:** 50–100 participants
- **Key Partners:** BayCare, Moffitt, Tampa VA
- **Replication Kit:** Local partner identification + data integration

## Phase 2: Florida State (Year 1–2)
- **Locations:** 3–5 counties
- **Target:** 200–500 participants
- **Key Partners:** State workforce, FDOT, Florida Housing
- **Replication Kit:** State-level funding map + regulatory alignment

## Phase 3: National (Year 2–3)
- **Locations:** 5–10 states
- **Target:** 1,000+ participants
- **Key Partners:** HUD, DOL, USDA
- **Replication Kit:** Federal compliance + national partnership network

## Phase 4: Global (Year 3–5)
- **Locations:** international metros
- **Target:** 10,000+ participants
- **Key Partners:** Local governments, international foundations
- **Replication Kit:** Cultural adaptation + language localization

---

## Replication Checklist

- [ ] Local needs assessment
- [ ] Partner mapping
- [ ] Funding identification
- [ ] Staff training (AI Academy)
- [ ] Data integration (local sources)
- [ ] Dashboard customization
- [ ] Pilot launch (10 participants)
- [ ] 90-day measurement
- [ ] Iteration and scale
